# Changes Made on 2026-03-17

Date: 2026-03-17

## Overview

Today’s work focused on improving AgenticNetSec for Deliverable 3 demo quality and rubric coverage. The changes were centered on stronger evidence-backed reporting, clearer guardrail traceability, richer runtime and cost metrics, frontend visibility for those new fields, and supporting benchmark/test assets.

The feedback source used to guide this work was `docs/FirstFeedback.md`. That file is reference input only and is not itself part of the implementation summary below.

## Backend Changes

- Extended the forensic report schema to support:
  - evidence references
  - MITRE ATT&CK mappings
  - evidence reference IDs
  - direct evidence summaries
  - uncertainty fields
- Extended run metrics to support:
  - provider and model recording
  - fallback-used state
  - artifact size tracking
  - cost assumption metadata
- Updated the analysis pipeline to:
  - build structured evidence references from supported detector families
  - map current findings to MITRE techniques with deterministic local rules
  - separate direct evidence from inference and uncertainty
  - produce richer structured report output
- Expanded guardrail logic to include:
  - consistency checks across claims and evidence
  - contradiction detection
  - audit-trace generation
  - explicit read-only mode signaling
- Refactored report generation metadata handling so provider responses can contribute:
  - token usage
  - provider name
  - selected model
  - fallback state
- Updated observability/cost handling so metrics now incorporate:
  - measured runtime
  - provider token counts when available
  - artifact byte sizes
  - documented pricing assumptions

## API and Artifact Changes

- Added a new API endpoint:
  - `GET /api/v1/analysis/{job_id}/guardrail-audit`
- Added a new persisted per-job artifact:
  - `guardrail_audit.json`
- The API job flow now saves:
  - `report.json`
  - `report.md`
  - `metrics.json`
  - `guardrail_audit.json`

## Frontend Changes

- Extended frontend transport and domain types additively to remain backward compatible.
- Updated the report view to display:
  - MITRE ATT&CK mappings
  - evidence references
  - direct evidence
  - uncertainty entries
  - evidence reference IDs
- Updated the raw artifacts view to display:
  - richer runtime/cost metrics
  - provider/model/fallback fields
  - artifact byte sizes
  - cost assumptions
  - a new guardrail audit tab for `guardrail_audit.json`
